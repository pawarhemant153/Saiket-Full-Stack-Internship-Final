# Saiket Full Stack Internship – Portfolio Project

##  Project Title
Personal Portfolio Website – Frontend (Task 1 & Task 2)

---

##  Project Description
This project is developed as part of the **Saiket Full Stack Internship**.

The project includes **Frontend Task 1 and Task 2**, combined into a single professional **portfolio website**.

The portfolio showcases:
- Personal information
- Skills
- Projects
- Certificates
- Training & Internship details
- Contact form with validation messages

---

##  Internship Tasks Covered

###  Task 1: Portfolio Website (Frontend)
- Created a responsive personal portfolio website
- Sections included:
  - Home
  - About
  - Skills
  - Projects
  - Certificates
  - Training & Internship
  - Contact
- Used modern UI with glassmorphism design

### Task 2: Contact Form with Validation (Frontend)
- Implemented contact form using JavaScript
- Validations included:
  - Empty field check
  - Email format validation
- Error message displayed in **red**
- Success message displayed in **green**

 Both Task 1 and Task 2 are implemented inside the **Frontend Portfolio project**
